# Go Final Project — Планировщик задач

## 1. Описание проекта

Проект представляет собой веб-приложение для управления задачами и напоминаниями.

Основные возможности:

- Создание задач.
- Просмотр списка задач.
- Редактирование задач.
- Удаление задач.
- Установка даты выполнения.
- Настройка повторения задач.
- Автоматическое вычисление следующей даты выполнения.
- Авторизация с использованием JWT.
- Веб-интерфейс на HTML, CSS и JavaScript.
- Хранение данных в SQLite.

## 2. Локальный запуск проекта

### Требования

- Go 1.26 или новее.

### Установка зависимостей

```bash
go mod download
```

### Настройка переменных окружения и запуск

Для запуска приложения необходимо передать следующие переменные окружения:

- `TODO_PASSWORD` — пароль для авторизации. Если переменная не задана или пуста, авторизация отключена.
- `TODO_JWT_SECRET` — секретный ключ для подписи JWT.

**macOS / Linux:**

```bash
TODO_PASSWORD="123" TODO_JWT_SECRET="secret" go run .
```

**Windows PowerShell:**

```powershell
$env:TODO_PASSWORD="123"; $env:TODO_JWT_SECRET="secret"; go run .
```

После запуска открой приложение в браузере:

http://localhost:7540

## 3. Запуск тестов

Для запуска всех тестов:

```bash
go test ./...
```

Для запуска с подробным выводом:

```bash
go test -v ./...
```

### Настройки тестирования

Настройки находятся в файле `tests/settings.go`.

Перед запуском тестов проверь следующие параметры:

```go
var Port = "7540"
var DBFile = "../scheduler.db"
var FullNextDate = true
var Search = true
```
